# Bitácora de ejemplo (ficticia)

**Esto es un ejemplo.** El equipo "99999Z", sus integrantes, la escuela, las fuentes citadas y todos los datos son inventados. Las imágenes de `fotos/` son dibujos de relleno generados para este ejemplo (sin derechos de terceros); cada una dice "IMAGEN DE EJEMPLO".

Sirve para probar el generador con todos los tipos de página: tablas largas (una prueba de 16 intentos, un mapa de 14 puertos), textos largos que pasan a una página de continuación, varias fotos en una misma página, referencias entre páginas y cuatro iteraciones encadenadas del mismo subsistema (el intake).

```
npm run generate -- examples/notebook-ejemplo/notebook.json --template template/V5_Engineering_Notebook_Template_ES.pptx --out output/ejemplo.pptx
```
